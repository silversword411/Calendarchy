# Calendarchy

Calendarchy is a native, Omarchy-first calendar application for working with
calendars on the Omarchy desktop. It is being built to provide a fast,
keyboard-friendly calendar experience that feels at home with Omarchy's
GTK4/libadwaita theme and system notifications.

The planned calendar client will support:

- Viewing and managing calendars from multiple Google accounts
- Month, week, day, agenda, and list views
- Offline-first local data with background synchronization
- Reminders through Omarchy's notification system
- Keyboard navigation and automatic light/dark theme integration

Calendarchy is currently in the design and pre-implementation stage. The
application is planned in Rust with GTK4/libadwaita and is initially targeting
Omarchy on Arch Linux.

See [`DESIGN_SPEC.md`](DESIGN_SPEC.md) for the current architecture, goals, and
implementation plan.
